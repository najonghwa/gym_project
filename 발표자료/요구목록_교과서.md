# 정제 교과서 요구 목록

요구의 출처는 사용자 말(2026-11-20)이다. 판정은 `점검_교과서.py`가 만든 HTML을 브라우저에서 다시 세어 내린다. 판정 기준은 그 파일에만 있고, 만드는 쪽(`교과서.py`)과 나눠 두었다.

## 사용자 요구

"이걸구해서 뭘어떻게쓰는지에대해 아직좀빈약한거같아. 교과서도 재정립하자. 쓸데없는건지우고 식도 최대한 단순화시켜서설명해주셈"

| 번호 | 요구 | 판정 항목 |
|---|---|---|
| T2 | 교과서 재정립: 지금 시뮬레이터가 계산하는 대로 다시 짠다 | T2-1 읽는 법 → 설비 구간 8개 → 피드백 루프 → 계산값과 현장값 → 용어 · T2-2 구간마다 요지 · 설명 · 넘기는 값 · 그림 · T2-3 읽는 법(항목 구성 4칸 · 전체 그림 · 값이 넘어가는 순서) |
| T3 | 구해서 무엇을 어떻게 쓰는지 | T3-1 항목 = 발표자료의 공식 35개(핵심 계산 카드 + 보조 계산 표) · T3-2 카드마다 산출값 → 용도(계산 · 운전, 있으면 적용 예) → 식의 요지 → 계산값 · T3-3 보조 계산 표의 줄마다 같은 칸 |
| T4 | 식의 단순화 | T4-1 계산값 · 식의 요지가 발표자료의 같은 공식과 같음 · T4-2 구간 그림의 말풍선 식 = 식의 요지(시뮬레이터 계산식은 항목마다 접어 둠) · T4-3 글의 숫자가 계산 기록과 같음 |
| T5 | 쓸데없는 것 삭제 | T5-1 예전 교과서의 내용이 남아 있지 않음(아래 '지운 것') · 예전 판은 `정제_교과서_이전판.html`로 보관 |
| T6 | (이동) | T6-1 구간 줄의 버튼을 누르면 그 절로 이동 |

## 풀이

- '재정립'은 예전 교과서(2026-11-11, 헥산–톨루엔 예로 쓴 일반 증류 교과서)를 다듬지 않고, 지금 시뮬레이터(CpHf 2차 정제, 구간 8개 · 공식 35개)의 계산 순서대로 새로 쓰는 것으로 풀었다.
- '구해서 뭘 어떻게 쓰는지'는 항목마다 용도를 둘로 나눠 적는 것으로 풀었다: 계산(구한 값이 다음에 어느 계산의 입력이 되는가) · 운전(그 값으로 무엇을 판단하고 어느 계기와 비교하는가). 입력 하나를 바꿔 본 이상 상황 시험 기록이 있으면 적용 예로 숫자를 붙였다.
- '식의 단순화'는 식의 요지(말로 쓴 식 또는 비례 관계 한 줄)를 앞에 두고, 시뮬레이터가 실제로 쓰는 계산식은 항목마다 접어 두는 것으로 풀었다. 식을 새로 지어내지 않았다(같은 식을 줄여 쓴 것이다).
- 내용은 발표자료와 같은 자료(`내용.py` · `용도.py` · 기록)에서 읽는다. 발표자료의 공식 카드도 같은 순서(산출값 → 용도 → 식의 요지 → 계산값)로 바꿨다(발표자료 요구 P11).
