# 정제 탱크 시뮬레이터

회분 정제(정제기 → 충전 컬럼 → 응축기 → 초류·본류 탱크)를 브라우저에서 돌려 보는 시뮬레이터.

현재 판: v130 · 11-20 14:20

v130은 '열 퍼짐 강조'를 기본 켜짐으로 바꾸고, 밸브를 닫은 뒤 관 속 액의 그림을 고친 판이다. 닫힌 밸브 앞의 액은 남고(유출 FCV-H072 · 본류 XV-H077 · 초류 XV-H074, 환류는 U자와 그 앞 구간), 뒤의 액은 관 끝으로 흘러 나가며 빈다. 관 속에 액이 있으면 밸브가 닫혀도 관을 유리로 그린다(전에는 불투명 회색이라 남은 액이 안 보였다). 도면에서는 멈춘 흐름의 점이 1초 동안 옅어지며 사라진다. 계산은 v129와 같다(빠지는 속도는 표시 규칙).

v129는 정제기 열 퍼짐 표현을 넣은 판이다. 가벼운 계산에서 '평균과의 온도 차'를 구획 계산으로 풀어(교반 섞임 = 혼합 시간 식, 교반 정지 = 자연대류 경계층 식) 3D 액 색에 반영한다. 교반 80 rpm이면 차이가 0.01 ℃라 한 색이고, 교반을 멈추면 위쪽 · 벽 쪽이 뜨거워진다. 밸브 줄의 '열 퍼짐 강조' 스위치(기본 꺼짐)를 켜면 평균보다 뜨거운 곳을 로그 눈금으로 붉게 덧칠하고, 벽을 지난 흐름 줄기가 붉어졌다 옅어진다. 평균 온도 · 증발 · 압력 계산은 v128과 같다.

v128은 화면을 손본 판이다. 그림: 컬럼 몸통 0.59 → 0.95 m · 목관 0.78 → 0.42 m, 충전층 구간을 길게(0.30 → 0.66 m, 실제 300 mm는 계산에만), 컬럼 옆 온도 띠의 파랑 없앰, 교반기가 뜨거운 액에서도 보이게, 본류 탱크 위 XV-H077 간격. 도면(2D): 증기 5줄(액면 전체), 컬럼 · 목관으로 내려오는 액, 응축기 관 안 액, 정제기 액 온도 색. 계산: 환류 U자 액봉 0.55 kg은 배치가 끝나도 관에 남는다(끝난 뒤 정제기 잔량 30.2 → 29.6 kg, 본류는 그대로). 새 값 상자: 1차 응축기 부하율(응축 능력 대비 %).

v127은 컬럼 위 환류 분배를 현장대로 작은 구멍 4개로 그린 판이다(3D 줄기 4개, 도면 구멍 4개와 떨어지는 액 점, 설비 설명 글). 원뿔 분사는 뺐다(작은 구멍에서는 액이 중력으로 줄기를 이룬다). 계산은 v126과 같다.

v126은 현장 배관 치수를 계산에 넣은 판이다(증기관 직관 4.7 m = 위 3 + 오른쪽 1.2 + 아래 0.5, U자 액봉 0.55 kg = 0.6 + 0.3 + 0.6 m, 정제기 위 공간 부피). 그림은 보기 좋게 v125 배치를 지킨다(사용자 결정). 그 밖에 화면 손질(도면 증기 점, 컬럼 예열 색, 환류 노즐 둘, 진공 라인 표시와 범례, 둥근 점, 밸브 머리 색, 본류 밸브 자리, 환류 계기 자리), 후류 정의(본류 = 투입 − 초류 − 후류), PIMS 태그(PIH093 · FIH071). 내역은 `적용_공식_정리.md`의 'v126' 절에 있다.

v125는 외부망 v117(공식 재점검 · 이상 상황)과 사내망 v117~v124(PIMS 태그 · P&ID 값 · 2D 도면)를 합친 판이다. 내역과 사내망에서 받는 법은 `사내망_합침_내역_v125.md`에 있다.

## 쓰는 법

1. 크롬이나 엣지로 `index.html`을 연다. 파일 하나로 동작하고 인터넷 없이 열린다.
2. 화면 제목 옆 판 번호가 위 '현재 판'과 같은지 확인한다.
3. 첫 화면은 그림 중심이다. 입력칸은 왼쪽 세로 단추(운전·물질·탱크·컬럼·유출·단열·펌프·표시)를 누르면 열린다.

## 그래픽이 약한 PC(VDI 등)

- 처음 몇 초 동안 속도를 재서, 그래픽 카드가 없으면 '가벼운 계산'(정제기 안 흐름 계산 끔)으로 자동 전환한다. 컬럼·응축기·배관 계산과 결과는 같다.
- 화면 품질은 깎지 않는다. 3D가 느리면 오른쪽 위 '도면으로 보기'를 누른다. 지금 설비 형상으로 그리는 2D 도면이고, 휠로 확대하고 끌어서 옮긴다.
- 3D를 가볍게 보려면 설정 '표시' 탭의 화질을 '화면 가볍게'로 바꾼다(화면을 다시 연다).

## 운전 모드

- 레시피: 승온 → 전환류 안정화 → 초류 → 본류 순서로 자동 운전.
- CpHf 정제 조건의 기본값: 투입 350 kg, 초류 30 kg, 후류(정제기에 남김) 30 kg, 환류 4 kg/h, 유출 초류 2 · 본류 6 → 정제기에 70 kg 남으면 5 kg/h. 3D 화면 왼쪽 아래 '배치 시트'에서 무게를 바꾸고 스타트한다.
- 수동: 운전 패널에서 고른다(스팀·환류·유출 밸브 개도).

## 이상 상황 보기

- 화면 아래 밸브 줄의 '이상 상황 ▸'을 누르면 평소 안 건드리는 밸브와 '상황 고르기'가 나온다.
- '상황 고르기'에서 12가지(N-Brine·L-Brine 온도, 냉매 유량, 스팀 개도 과다, 환류 과다·부족, 진공 리크·배기 능력·펌프 정지, 외기 한파, 단열 손상)를 지금 배치에 건다. 다시 누르면 되돌린다.
- 3D 화면의 값 상자 중 '스팀 개도', '환류', 'N-Brine', 'L-Brine'은 누르면 값을 바꾼다. 값 상자에 마우스를 올리면 PIMS 태그가 보인다.
- 입력칸 앞 배지: '도면'은 P&ID·장치 조립도에서 온 값, '가정'은 도면·운전 데이터로 정할 수 있는 값, '추정'은 데이터를 받아도 정하기 힘든 값이다.
