# 정제 탱크 시뮬레이터

회분 정제(정제기 → 충전 컬럼 → 응축기 → 초류·본류 탱크)를 브라우저에서 돌려 보는 시뮬레이터.

현재 판: v125 · 11-18 21:45

v125는 외부망 v117(공식 재점검 · 이상 상황)과 사내망 v117~v124(PIMS 태그 · P&ID 값 · 2D 도면)를 합친 판이다. 내역과 사내망에서 받는 법은 `사내망_합침_내역_v125.md`에 있다.

## 받는 법

```bash
git clone -b distill-sim --single-branch https://github.com/najonghwa/gym_project.git distill-sim
```

새 판을 받을 때는 그 폴더에서 `git pull`. 로컬에서 `index.html`을 고친 커밋이 있으면 `사내망_합침_내역_v125.md` 4절의 순서로 받는다(글 단위로 합치지 않는다).

git 없이 받으려면 아래 주소의 zip을 받는다.
https://github.com/najonghwa/gym_project/archive/refs/heads/distill-sim.zip

## 쓰는 법

1. 크롬이나 엣지로 `index.html`을 연다. 파일 하나로 동작하고 인터넷 없이 열린다.
2. 화면 제목 옆 판 번호가 위 '현재 판'과 같은지 확인한다.
3. 첫 화면은 그림 중심이다. 입력칸은 왼쪽 세로 단추(운전·물질·탱크·컬럼·유출·단열·펌프·표시)를 누르면 열린다.

## 그래픽이 약한 PC(VDI 등)

- 처음 몇 초 동안 속도를 재서, 그래픽 카드가 없으면 '가벼운 계산'(정제기 안 흐름 계산 끔)으로 자동 전환한다. 컬럼·응축기·배관 계산과 결과는 같다.
- 화면 품질은 깎지 않는다. 3D가 느리면 오른쪽 위 '도면으로 보기'를 누른다. 지금 설비 형상으로 그리는 2D 도면이고, 휠로 확대하고 끌어서 옮긴다.
- 3D를 가볍게 보려면 설정 '표시' 탭의 화질을 '화면 가볍게'로 바꾼다(화면을 다시 연다).

## 운전 모드

- 레시피: 승온 → 전환류 안정화 → 초류 → 본류 순서로 자동 운전.
- CpHf 정제 조건의 기본값: 투입 350 kg, 초류 30 kg, 후류(정제기에 남김) 30 kg, 환류 4 kg/h, 유출 초류 2 · 본류 6 → 정제기에 70 kg 남으면 5 kg/h. 3D 화면 왼쪽 아래 '배치 시트'에서 무게를 바꾸고 스타트한다.
- 수동: 운전 패널에서 고른다(스팀·환류·유출 밸브 개도).

## 이상 상황 보기

- 화면 아래 밸브 줄의 '이상 상황 ▸'을 누르면 평소 안 건드리는 밸브와 '상황 고르기'가 나온다.
- '상황 고르기'에서 12가지(N-Brine·L-Brine 온도, 냉매 유량, 스팀 개도 과다, 환류 과다·부족, 진공 리크·배기 능력·펌프 정지, 외기 한파, 단열 손상)를 지금 배치에 건다. 다시 누르면 되돌린다.
- 3D 화면의 값 상자 중 '스팀 개도', '환류', 'N-Brine', 'L-Brine'은 누르면 값을 바꾼다. 값 상자에 마우스를 올리면 PIMS 태그가 보인다.
- 입력칸 앞 배지: '도면'은 P&ID·장치 조립도에서 온 값, '가정'은 도면·운전 데이터로 정할 수 있는 값, '추정'은 데이터를 받아도 정하기 힘든 값이다.

## 점검(사내망 Claude Code)

- `CLAUDE.md`: Claude Code가 이 폴더에서 일할 때 먼저 읽는 작업 기준서. 글 규칙, 값의 기준, 계산·그림 원칙, 다섯 단계 점검 순서(요구 목록 → 점검기 → 숫자 기준 루프 → 보고)가 들어 있다.
- `점검/점검.py`: 시뮬레이터를 실제 브라우저로 돌려 요구마다 숫자로 판정한다. `python 점검/점검.py --tag 이름`
- `점검/회귀/회귀.py`: 계산을 바꾼 뒤 직전 배포판과 결과를 나란히 본다. `python 점검/회귀/회귀.py`
- 필요한 것: Python 3, Node.js(Claude Code를 쓰면 이미 있음), 크롬 또는 엣지.
- 요구 목록(`점검/요구목록.md`)과 계산 근거 문서(`적용_공식_정리.md`)도 이 저장소에 있다. 판마다 함께 갱신된다.
- `현장_데이터_맞춤_안내.md`: 현장 데이터와 도면값으로 시뮬레이터 값을 정하는 순서, 데이터로도 정하기 힘든 값, 이상 상황 목록, 남은 일과 코드 자리.
- `사내망_합침_내역_v125.md`: 사내망 변경내역을 합친 내역, 추가 점검 문서 검토, 운전 개념, 현장 그래프와 견준 표.
- `점검/점검_공식.py`: 식 독립 검산과 이상 상황 반응 시험. `python 점검/점검.py --only 공식,이상 --tag 이름`
- `점검/점검_합침.py`: 사내망 변경내역·추가 점검·운전 개념이 들어갔는지 보는 항목(M·N). `python 점검/점검.py --only 합침 --tag 이름`
