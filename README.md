# 🏋️ 회사 헬스 가이드 (웹앱 · Vercel 배포용)

폰에서 잘 보이는 **정적 웹앱**. Tailwind CSS(shadcn 스타일 다크 테마) 기반.
서버가 필요 없고 모든 데이터는 사용하는 그 기기(브라우저)에 저장됩니다(localStorage).

## 기능

- **아이디 입장** — 아이디만 만들면 시작 (비밀번호 없음)
- **7단계 온보딩** — 기본정보(몸무게는 **선택** — 비우면 평균값으로 계산) · 운동경력 · 추구 스타일(벌크업/린매스업/다이어트/파워리프팅/토닝/건강) · 주당 횟수 · 운동 시간 · 집중 부위 · **분할 자동 추천+설명**
- **오늘 탭** — 세트별 체크(1·2·3·4), 달성률 링, **동기부여 멘트**(1,000개+ 조합, 매일 다름)
- **러닝 탭 (선택 참여)** — 성향 진단(경험·목표·주당횟수·체력) → **이지런·템포·인터벌·장거리·단거리·회복런**을 섞은 주간 플랜. 거리+페이스만 입력하는 간단 기록, 이번 주 목표 대비 달성률, 러닝 랭킹(이번주/이번달/누적 km)
- **달력** — 운동한 날 색 표시(100%=초록/부분=노랑), 이달 평균 달성률
- **루틴 탭** — 내 루틴 + **나만의 루틴 만들기(빌더)** + **공유 루틴**(업로드·좋아요·적용)
- **랭킹 탭** — 출석률/연속출석/총운동/XP 사내 랭킹
- **헬스장 탭** — **SVG 평면도**, 장비 누르면 설명·사용팁·관련 운동
- **내정보(우상단)** — 예측(kcal/체지방/근육량)·식단팁·뱃지 8종·프로필

## Supabase(서버 DB) 연동 — 랭킹·공유를 진짜로 만들기

연동하면: 아이디별 데이터가 서버에 저장(다른 폰에서 같은 아이디로 이어짐),
랭킹·러닝랭킹·공유루틴이 실제 동료들과 실시간 공유됩니다. **5분 소요:**

1. [supabase.com](https://supabase.com) 가입 → **New project** (무료)
2. 프로젝트 → **SQL Editor** → New query → 이 폴더의 `supabase.sql` 내용 붙여넣고 **Run**
3. 프로젝트 → **Settings → API** 에서 `Project URL`과 `anon public` 키 복사
4. `js/config.js` 를 열어 두 값을 붙여넣기 → 저장 → 재배포(또는 새로고침)

끝. 비워두면 지금처럼 기기 저장 + 예시 데이터로 동작합니다.
(주의: 비밀번호 없는 사내 데모용 개방 정책입니다 — 외부 공개 시 Auth 도입 권장)

## 로컬 미리보기

```
python -m http.server 8091 --directory gym_web
```
→ http://localhost:8091

## Vercel 배포

1. 프로젝트를 GitHub에 올림
2. vercel.com → Add New → Project → 저장소 선택
3. **Root Directory = `gym_web`**, Framework = **Other** → Deploy
4. 나온 주소를 폰에서 열고 "홈 화면에 추가"

## 실제 장비/레이아웃 반영하기

`js/data.js` 만 교체하면 됩니다:
- `ZONES` — 구역 이름·색
- `FLOOR_ZONES` — 평면도 구역 사각형 좌표 (SVG viewBox 400×310)
- `FLOOR` — 장비 위치(x,y)·아이콘
- `EQUIP_INFO` — 장비 설명·사용 팁
- `EXERCISES` — 운동 목록(장비 문자열은 FLOOR의 eq와 동일해야 함)

루틴·예측·화면은 이 데이터를 그대로 읽으므로 다른 파일은 안 건드려도 됩니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 셸 + Tailwind 설정 + Pretendard 폰트 |
| `js/config.js` | **Supabase URL/키 (연동 시 여기만 채우면 됨)** |
| `js/supa.js` | Supabase 동기화 레이어 (미설정 시 자동 비활성) |
| `supabase.sql` | Supabase 테이블 생성 스크립트 |
| `js/data.js` | **장비/평면도/스타일/분할 데이터 (실제 정보로 교체할 파일)** |
| `js/quotes.js` | 동기부여 멘트 (210개 본문 × 5개 = 1,050 조합) |
| `js/run.js` | 러닝 성향 진단 · 주간 플랜 · 페이스/통계 |
| `js/core.js` | 분할 추천 · 루틴 생성 · 예측 · 점수 |
| `js/store.js` | localStorage 저장 · 통계 · 뱃지 · 커스텀/공유 루틴 · 랭킹 · 서버 푸시 |
| `js/app.js` | 전체 화면/상호작용 |

## 한계 / 다음 단계

- 데이터는 기기별 localStorage — **랭킹·공유 루틴의 '동료'는 예시(데모)**입니다.
  실제 사내 공유/랭킹은 서버(Supabase, Vercel KV 등)를 붙이면 그대로 확장됩니다.
- Tailwind는 CDN 방식(빌드 불필요). 트래픽이 커지면 빌드 방식으로 전환 가능.
- 예측치는 어림값 기반의 대략적 추정입니다.
