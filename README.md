v142는 CpHf 조건의 분배 방식을 '유출 유량 고정(FICH072) · 나머지 환류'로 바꾼 판이다(사용자 결정 2026-11-25). 스팀이 레시피 개도면 증발이 개도로 정해져 환류와 유출을 둘 다 설정값으로 둘 수 없는데, v141까지는 환류를 4 kg/h로 고정해 초류 유출이 설정 2 kg/h보다 많았다. 이제 유출이 설정대로(초류 2 · 본류 6 → 정제기 70 kg부터 5 kg/h) 나오고 환류가 나머지가 되어, 초류 단계가 약 5.7시간 길어지고 배치는 약 66시간에 끝난다. 레시피 운전에서 값 상자를 누르면 고정한 쪽만 설정 창이 뜬다. 새 디자인에서는 응축기 아래 분배기(티)를 다시 그렸다 — 응축액 관 줄기가 분배기 액면 위에서 관 굵기로 매끄럽게 이어지고, 분배기 · 환류 쪽 액도 다른 관처럼 줄기 빠르기로 흐른다(전: 굵기가 선을 그은 듯 갈라지고, 무늬가 위로 가고, 장면마다 깜빡였다). 액이 지나가는 길을 정제기 액면부터 받는 탱크까지 구간마다 따라가 보고(사용자 요청) 세 가지를 고쳤다. 김 띠에 생기던 각진 조각(잡음 함수의 격자 꼭짓점 값이 이웃 칸에서 어긋남), 응축기 관 벽 액막의 네모 조각(양면 반투명을 한 번에 그림), 초류를 받는 동안 비어 있던 본류 쪽 막힌 다리다. 승온 중 정제기 액 속 김처럼 보이던 자켓 안 김 띠도 뺐다. 스팀은 투명한 기체이고, 진공에서는 액 무게 때문에 깊이마다 끓는점이 크게 올라(0.1 torr에서 액면 70 ℃ → 3.5 cm 아래 116 ℃) 기포는 끓을 때 액면 바로 아래에서만 생긴다. 계산에서는 U자 액봉이 덜 찬 동안 유출까지 막던 것을 고쳤다. U자는 환류 쪽(FCV-H073 뒤)이라 환류 몫으로만 차고, 유출은 밸브가 열려 있으면 처음부터 분배대로 흐른다(레시피 기본 흐름은 U자가 전환류 단계에 차므로 결과가 같다). 밸브는 관보다 굵은 몸통으로 관 속 액을 가리고 몸통 전체를 열림 초록 · 닫힘 빨강으로 칠했으며, 정제기 위 김은 곧은 원뿔 대신 노즐 가까이에서 휘어 모이며 빨라지는 깔때기로 그린다. 이상 상황 '환류 과다 · 부족'은 유출 고정 분배에서 유출 설정을 0.2배 · 3배로 바꿔 건다(환류 칸은 유출 고정에서 쓰이지 않아 전에는 걸리지 않았다). 자세한 내용은 `적용_공식_정리.md`의 v142 절에 있다.

v127은 컬럼 위 환류 분배를 현장대로 작은 구멍 4개로 그린 판이다(3D 줄기 4개, 도면 구멍 4개와 떨어지는 액 점, 설비 설명 글). 원뿔 분사는 뺐다(작은 구멍에서는 액이 중력으로 줄기를 이룬다). 계산은 v126과 같다.

v126은 현장 배관 치수를 계산에 넣은 판이다(증기관 직관 4.7 m = 위 3 + 오른쪽 1.2 + 아래 0.5, U자 액봉 0.55 kg = 0.6 + 0.3 + 0.6 m, 정제기 위 공간 부피). 그림은 보기 좋게 v125 배치를 지킨다(사용자 결정). 그 밖에 화면 손질(도면 증기 점, 컬럼 예열 색, 환류 노즐 둘, 진공 라인 표시와 범례, 둥근 점, 밸브 머리 색, 본류 밸브 자리, 환류 계기 자리), 후류 정의(본류 = 투입 − 초류 − 후류), PIMS 태그(PIH093 · FIH071). 내역은 `적용_공식_정리.md`의 'v126' 절에 있다.

v125는 외부망 v117(공식 재점검 · 이상 상황)과 사내망 v117~v124(PIMS 태그 · P&ID 값 · 2D 도면)를 합친 판이다. 내역과 사내망에서 받는 법은 `사내망_합침_내역_v125.md`에 있다.

## 그래픽이 약한 PC(VDI 등)

- 3D 표현은 두 가지다: 새 디자인(기본)과 가벼움(v131 화면). 소프트웨어 렌더링(그래픽 카드 없음) · 화질 '화면 가볍게' · WebGL 없음이면 가벼움으로 열고, 고르지 않았는데 새 디자인이 초당 20장 아래로 5초 넘게 이어지면 가벼움으로 바꾼다. 머리줄 '표현'에서 고르거나 주소 끝에 `#lite` · `#design`을 붙인다.
- 처음 몇 초 동안 속도를 재서, 그래픽 카드가 없으면 '가벼운 계산'(정제기 안 흐름 계산 끔)으로 자동 전환한다. 컬럼·응축기·배관 계산과 결과는 같다.
- 화면 품질은 깎지 않는다. 3D가 느리면 오른쪽 위 '도면으로 보기'를 누른다. 지금 설비 형상으로 그리는 2D 도면이고, 휠로 확대하고 끌어서 옮긴다.
- 3D를 가볍게 보려면 설정 '표시' 탭의 화질을 '화면 가볍게'로 바꾼다(화면을 다시 연다).

- 화면 아래 밸브 줄의 '이상 상황 ▸'을 누르면 평소 안 건드리는 밸브와 '상황 고르기'가 나온다.

- 3D 화면의 값 상자 중 '스팀 개도', '환류', 'N-Brine', 'L-Brine'은 누르면 값을 바꾼다. 값 상자에 마우스를 올리면 PIMS 태그가 보인다.
