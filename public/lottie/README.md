# Lottie 마스코트 애니메이션

LottieFiles(무료·상업 OK)에서 받은 `.json`을 여기에 넣으면 자동으로 판다 대신 재생됩니다.
파일이 없으면 판다 SVG가 폴백으로 보입니다. (앱은 정상 동작)

## 파일 이름 규칙 (이 이름 그대로 저장)
| 파일 | 위치 | 지금 폴백 |
|------|------|-----------|
| `hero.json` | 로그인 화면 | 리프트 판다 |
| `gym.json` | 헬스 홈 헤더 | 리프트 판다 |
| `run.json` | 러닝 탭 헤더 | 러닝 판다 |
| `analysis.json` | 분석 헤더 | 플렉스 판다 |
| `celebrate.json` | 운동 완주 축하 | 플렉스 판다 |
| `coach.json` | 루틴 추천 | 코치 판다 |

## 받는 법
1. https://lottiefiles.com/free-animations/fitness (또는 "workout bear/panda/animal" 검색)
2. **Free** 라벨 확인 → `Download → Lottie JSON`
3. 위 이름으로 이 폴더에 저장 (예: `gym.json`)
